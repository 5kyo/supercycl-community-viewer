# 프로젝트 컨텍스트

## 목적과 작업 위치

Supercycl 커뮤니티의 관리자 대시보드를 데스크톱 웹에서도 조회하는 방식을 YouthMeta 담당자와 협의하기 위한 목업입니다. 시연 로그인 후 담당 채널의 정보를 확인하며, 수정·관리 조작은 제공하지 않습니다.

주 작업 폴더는 `Projects/Supercycl-Community-Viewer/`입니다. 기존 공개 저장소 `5kyo/supercycl-community-viewer`의 커밋 이력과 GitHub Pages를 이어서 사용합니다. 프로젝트를 열 때는 이 폴더를 선택합니다.

## 구현되어 있는 화면

| 화면 | 조회 내용 |
| --- | --- |
| 로그인 | 미리 채워진 시연 계정으로 입장, 실제 인증 없음 |
| 대시보드 | 상단 손익 요약, 검토 대기 신고·적용 중 제재·연동 미완료·포지션 주의 요약, 대기 신고와 주의 멤버, 연동 현황 |
| 멤버 현황 | 검색·연동 상태 필터·정렬·페이지 이동, 멤버별 포지션 상세 |
| 포지션 주의 | 포지션 역주문·손실 경고 |
| 신고 현황 | 사유·처리 상태·조치 결과, 검색·필터·상세 이력 |
| 제재 현황 | 종류·범위·시행 주체·적용·해제 이력, 관련 신고 이동 |
| 채널 정보 | 그룹 기본 정보와 뷰어 조회 범위 |

문샷 서클과 알파 스쿼드 두 가상 채널을 전환할 수 있습니다. HTML 안에 스타일·스크립트·데이터·로고가 포함되어 외부 데이터 요청 없이 동작합니다.

## 유지할 결정 사항

- 데스크톱을 주 사용 환경으로 하며 작은 화면에서도 조회할 수 있습니다.
- 채널 선택 영역은 별도 제목과 버튼, 선택 상태를 표시합니다.
- 모든 화면은 조회 전용입니다. 실제 로그인과 접근 통제는 구현되지 않았습니다.
- 상단의 '가상 데이터 · 검토용 목업' 문구와 '검토 안내' 버튼은 사용자 요청으로 제거했습니다. 로그인 화면과 README에는 시연 범위를 설명합니다.
- 개인 차단과 포지션 경고는 제재 통계와 분리합니다. 신고 처리 결과와 현재 제재 상태도 별도로 표시합니다.
- 공개 저장소에는 합성 데이터와 공개 가능한 목업 자료를 관리합니다.

## 관리자 조회 동선

- 첫 화면은 채널 선택 바로 아래에 손익 요약을 먼저 보여줍니다. 그 아래에 운영 현황 4종, 확인할 신고·멤버, 연동 현황을 차례로 배치합니다.
- 요약 버튼은 각각 검토 대기 신고, 적용 중 제재, 연동 미완료 멤버, 포지션 주의 멤버 목록으로 이동합니다. 검토 대기는 접수와 검토 중 상태를 합친 조회 조건이며 새로운 처리 상태가 아닙니다.
- 신고·제재 목록은 상태별 전체 건수를 표시합니다. 검색·사유 필터를 조합할 수 있고 선택한 조건의 결과 수는 목록에 별도로 표시합니다. 기본 정렬은 검토 대기 또는 적용 중 우선이며 최신순·오래된순도 선택할 수 있습니다.
- 대시보드의 대기 신고는 접수 오래된 순으로 최대 3건을 보여줍니다. 목록 보기에서 전체 대기 신고를 확인합니다.
- 멤버 목록은 방장을 포함해 검색·필터에 일치하는 멤버를 집계하고 페이지를 나눕니다. 조건에 맞지 않는 내 계정을 고정 표시하지 않습니다. 손익 집계에서 방장·부방장을 제외하는 기준은 동일합니다.
- 채널을 전환하거나 다른 메뉴로 이동하면 검색·필터를 초기화합니다. 상세 창은 목록 위에서 열리며 닫으면 해당 목록으로 돌아갑니다.
- 작은 화면에서는 메뉴 이름을 상단에 표시하고, 넓은 표는 표 영역 안에서 가로로 스크롤합니다.

## 모바일 프로젝트 참조

같은 `Projects/` 아래에 `Supercycl-Mobile/`이 있을 때 아래 상대 경로에서 정책을 참고할 수 있습니다. 경로는 이 프로젝트 루트를 기준으로 하며 모바일 프로젝트가 없으면 소유자에게 최신 자료를 확인합니다. 모바일 저장소의 문서는 이 저장소의 실행 의존성이 아닙니다.

| 확인할 내용 | 참고 위치 |
| --- | --- |
| 커뮤니티·멤버십·신고·제재의 최신 정책 | `../Supercycl-Mobile/_workspace/spec/01_spec.md`의 YouthMeta 관련 절 |
| 채팅·관리자·그룹·랭킹·신고 처리 화면 정의 | `../Supercycl-Mobile/_workspace/spec/01_spec_screens/SCR-901.md` ~ `SCR-909.md` 중 영향 화면 |
| 모바일에서 구현한 인터랙션 참고 | `../Supercycl-Mobile/assets/design-spec/community.js` |

이 웹 목업에 구현된 신고·제재 조회는 작성 당시의 협의용 제안입니다. 모바일 정책은 독립적으로 변경될 수 있으므로, 향후 관련 화면을 수정하기 전에 최신 원문과 차이를 확인합니다. 웹 뷰어 수정만으로 모바일 정책을 변경하지 않습니다.

## 아직 협의할 내용

- 실제 인증 방식과 별도 뷰어 계정 제공 여부
- 계정별 조회 가능한 채널·멤버 정보와 신고·제재 기록의 범위
- 실제 데이터 API 및 갱신 주기
- 신고 처리 단계·심사 주체·제재 적용 범위·해제 기준을 웹 조회 화면에 반영하는 방식

## 소스와 배포본

`index.html`이 원본이고 GitHub Pages는 저장소의 `main` 루트를 게시합니다. 독립 프로젝트에서 관리하므로 데스크톱의 `슈퍼사이클_커뮤니티_뷰어_목업.html` 복사본은 계속 갱신하지 않습니다. 별도 요청이 있을 때만 공유본을 갱신합니다. 실행·Git·배포 명령은 [README](../README.md)에 있습니다.
