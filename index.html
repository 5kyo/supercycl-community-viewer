이번 목업의 범위

로그인은 시연용이며 실제 계정이나 비밀번호를 사용하지 않습니다. 모든 데이터는 파일 안에 포함된 가상 데이터입니다. 새로고침 버튼은 같은 시연 데이터를 다시 표시합니다.

조회 범위의 기본 가정

기존에 관리자 권한을 가진 담당자가 자신이 관리하는 그룹을 조회한다고 가정했습니다. 방장·부방장은 손익 집계와 경고 대상에서 제외하며, 계정 잔고는 표시하지 않습니다.

신고·제재 조회 검토안

신고 사유 4종과 채널 강퇴·차단 규칙은 모바일 커뮤니티 정책을 참고했습니다. 신고자는 공개하지 않으며 신고 메모와 원문·첨부도 이 뷰어에 포함하지 않습니다. 개인 차단과 포지션 경고는 제재로 집계하지 않습니다.

신고 현황의 뷰어 공개, 처리 단계와 이력 필드, 운영 제재의 세부 범위·해제 기준은 협의용 예시입니다. 신고 심사 주체는 Supercycl 운영을 가정하며 유스메타 합의가 필요합니다. 신고자에게 결과 알림을 보내는 기능은 없습니다.

유스메타와 함께 정할 내용

  • 기존 관리자 계정 로그인과 별도 뷰어 계정 중 사용할 방식
  • 뷰어 계정에 허용할 그룹과 멤버 정보 범위
  • 실제 데이터 갱신 주기와 웹 전용 조회 권한
  • 신고·제재 기록의 조회 대상, 공개 범위와 처리 단계
